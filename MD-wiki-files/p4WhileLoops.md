# How to use
```lua
while true do
 -- your code thingy here
 wait(1) -- you have to put in a wait otherwise it breaks and Roblox shouts at you
end
```
This code will make a loop that lasts forever and never ends ever unless the sript stops.
```lua
local baba = 1

while baba == 1 do
 -- your code thingy here
 wait(0.1) -- you have to put in a wait otherwise it breaks and Roblox shouts at you
end
```
This code will make a loop that lasts until this value changes from the set number thingymabobington.
> [!WARNING]
> Always put a wait in your loop. ALL THE TIME. ALWAYS. Otherwise roblox shouts at you.
## infinate loops
to make an infinite loop you can do a ``while true do`` like this
```lua
while true do
    wait(0.1)
    print("hello world")
end
```
this will keep going for as long as true is true witch is alwasy is
